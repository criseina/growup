# UI / UX Guide

> GrowUp 앱의 사용자 경험 및 화면 구성 기준

---

# 기본 원칙

- 아이가 혼자 사용할 수 있어야 한다.
- 그림이 글보다 먼저 보인다.
- 행동(Action)이 중심이다.
- 평가하지 않는다.
- 사용 흐름은 최대한 단순해야 한다.

---

# 사용자 모드

## 아이 모드

목적

- 스스로 행동을 선택한다.
- 현재 할 수 있는 정도를 표현한다.

화면 구성

- 큰 그림
- 행동 이름
- 상태 선택

상태

🟢 혼자

🟡 같이

⚪ 안 해봤어요

---

## 부모 모드

목적

- 행동을 관찰한다.
- 성장을 기록한다.
- 다음 행동을 추천받는다.

표시 정보

- 행동 목표
- 상태 기준
- 부모 팁
- 선행 행동
- 다음 추천 행동

---

# 카드 화면

카드에는 다음 정보가 표시된다.

- 행동 그림
- 행동 이름
- 상태 선택

아이 화면에는 설명을 최소화한다.

---

# 디자인 원칙

- 터치하기 쉬운 큰 버튼
- 최소한의 글자
- 직관적인 아이콘
- 밝고 편안한 색상
- 복잡한 애니메이션 사용 금지

---

# 성장 기록

성장 기록은 평가가 아닌 관찰 기록이다.

점수, 랭킹, 경쟁 요소는 포함하지 않는다.
