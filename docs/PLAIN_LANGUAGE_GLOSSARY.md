# 쉬운 용어표

문서와 대화에서 어려운 말이 반복해서 쌓이지 않도록 관리하는 표입니다. 새로운 기술 용어가 필요하면 이 표에 쉬운 설명을 먼저 추가합니다.

| 어려운 말 | GrowUp에서 쓰는 쉬운 뜻 |
|---|---|
| Flutter | Android와 여러 환경에서 앱을 만들기 위한 개발 도구 |
| APK | Android 휴대폰에 앱을 설치하는 파일 |
| QR 코드 | 휴대폰 카메라로 읽어 설치 주소를 여는 네모난 코드 |
| 프로토타입 | 실제 사용을 시험하기 위해 주요 기능을 먼저 연결한 앱 |
| 데이터 | 행동 카드, 아이의 선택, 메모처럼 앱이 기억하는 내용 |
| JSON | 행동 카드 내용을 일정한 형식으로 정리한 파일 |
| 로컬 저장 | 인터넷 서버가 아니라 현재 기기 안에 내용을 보관하는 방식 |
| 프로필 | 아이 한 명의 기록과 보상을 따로 묶는 단위 |
| 저장소(Repository) | 앱의 기록을 읽고 저장하는 코드 |
| 상태 머신(State machine) | 캐릭터가 걷기, 쉬기, 손 흔들기 같은 상태를 차례로 바꾸는 규칙 |
| 좌표 | 방 안에서 캐릭터나 물건이 놓이는 위치 |
| 걷는 영역 | 캐릭터가 가구와 벽을 피해 움직일 수 있는 바닥 범위 |
| 충돌 영역 | 캐릭터가 가구를 뚫고 지나가지 않게 막아 둔 범위 |
| 배치 자리(Slot) | 비누는 세면대 옆처럼 물건을 놓을 수 있게 정한 자리 |
| 기본 물건 | 처음부터 방에 있고 위치를 바꿀 수 없는 세면대·침대 같은 물건 |
| 획득 물건 | 행동 경험 뒤에 얻어 공간에 배치할 수 있는 비누·컵 같은 물건 |
| 스프라이트 | 캐릭터의 한 자세나 동작을 보여 주는 투명 배경 그림 |
| 그림 모음(Atlas) | 여러 자세 그림을 한 파일에 모아 필요한 부분만 보여 주는 방식 |
| 핫스팟 | 화면에서 터치하면 물건과 상호작용하도록 정한 영역 |
| 자동 검사 | 기능이 바뀌어도 중요한 동작이 깨지지 않았는지 코드가 확인하는 과정 |
| HTTP 200 | 다운로드 주소가 정상적으로 응답했다는 표시 |
| UTF-8 | 한글이 깨지지 않게 저장하는 글자 형식 |

## 문서 갱신 규칙

- 같은 어려운 말을 두 번 이상 쓰게 되면 이 표에 추가합니다.
- 화면에 보이는 말은 기술 용어보다 사용자가 이해하는 말을 우선합니다.
- 개발 기록에는 “무엇을 만들었는지”보다 “사용자에게 무엇이 달라졌는지”를 먼저 씁니다.
- 아직 휴대폰에서 확인하지 않은 기능은 “완료”가 아니라 “구현 후 확인 필요”로 씁니다.
