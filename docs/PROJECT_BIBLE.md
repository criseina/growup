# GrowUp Project Bible

> 아이와 부모가 함께 성장하는 행동 관찰 앱

---

# Mission

GrowUp은 아이를 평가하는 앱이 아니다.

아이의 행동을 관찰하고,
부모와 함께 성장 과정을 기록하는 앱이다.

---

# Core Philosophy

- 아이는 평가받지 않는다.
- 부모는 채점자가 아니다.
- 행동을 중심으로 성장한다.
- 보상은 성장을 기념한다.
- 아이가 혼자 사용할 수 있어야 한다.

---

# Status System

🟢 혼자

🟡 같이

⚪ 안 해봤어

---

# Parent Mode

부모는

- 행동을 관찰한다.
- 성장 발자국을 기록한다.
- 다음 행동을 추천받는다.

---

# Child Mode

아이가 스스로 사용할 수 있도록

- 큰 그림
- 짧은 제목
- 간단한 선택

만 제공한다.

---

# Current Goal

필수 행동을 쉬운 순서로 연결한 행동 트리 완성

카드 수를 목표로 하지 않는다. 중복되지 않고 아이가 독립적으로 관찰·선택할 수 있는 필수 행동만 카드로 만든다.

---

# Development Rule

기능보다 콘텐츠를 먼저 만든다.

행동의 순서와 카드 원본을 검토한 뒤 앱을 개발한다.
