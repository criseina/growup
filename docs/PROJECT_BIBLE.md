# GrowUp Project Bible

> 아이와 부모가 함께 성장하는 행동 관찰 앱

---

# Mission

GrowUp은 아이를 평가하는 앱이 아니다.

아이의 행동(Action)을 관찰하고,
부모와 함께 성장 과정을 기록하는 앱이다.

---

# Core Philosophy

- 아이는 평가받지 않는다.
- 부모는 채점자가 아니다.
- 행동(Action)을 중심으로 성장한다.
- 보상은 성장을 기념한다.
- 아이가 혼자 사용할 수 있어야 한다.

# Parent Mode

부모는

- 행동을 관찰한다.
- 성장 발자국을 기록한다.
- 다음 행동을 추천받는다.

---

# Child Mode

아이가 스스로 사용할 수 있도록

- 큰 그림
- 짧은 제목
- 간단한 선택

만 제공한다.
