# Action Card Library Master

> GrowUp 프로젝트의 모든 Action Card를 관리하는 마스터 문서

---

# 목적

이 문서는 Action Card Library의 단일 기준(Single Source of Truth)이다.

모든 Action Card는 이 문서를 기준으로 관리하며 다음 데이터의 기준이 된다.

- Flutter UI
- JSON 데이터
- 부모 모드
- 아이 모드
- 추천 시스템

---

# 카드 상태

- Draft (작성 중)
- Review (검토 중)
- Complete (완료)

# 카드 구성 규칙

모든 카드는 아래 정보를 가진다.

- 카드 ID
- 영역
- 한글 제목
- 영문 제목
- 난이도
- 아이 카드
- 부모 카드
- 선행 행동
- 다음 행동
- JSON ID
- 상태

카드 수는 품질 목표가 아니다. 새 카드는 기존 카드로 관찰할 수 없는 독립 행동일 때만 추가한다. `자립`은 별도 영역이 아니라 모든 카드의 관찰 상태로 판단한다.
