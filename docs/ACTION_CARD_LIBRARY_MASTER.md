# Action Card Library Master

> GrowUp 프로젝트의 모든 Action Card를 관리하는 마스터 문서

---

# 목적

이 문서는 Action Card Library의 단일 기준(Single Source of Truth)이다.

모든 Action Card는 이 문서를 기준으로 관리하며 다음 데이터의 기준이 된다.

- Flutter UI
- JSON 데이터
- 부모 모드
- 아이 모드
- 추천 시스템

---

# 카드 상태

- Draft (작성 중)
- Review (검토 중)
- Complete (완료)

- 영역

- 영문 제목
- 난이도
- 아이 카드
- 부모 카드
