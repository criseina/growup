## 1. 아바타 공간이 실제 방처럼 보이지 않았던 문제

### 문제

- 캐릭터가 방 한가운데 떠 있는 것처럼 보였습니다.

- 행동 카테고리와 물건이 놓이는 공간이 어긋나는 경우가 있었습니다.
- 물건을 자유롭게 놓으면 세면대나 선반과 맞지 않는 위치에 놓일 수 있었습니다.

### 시도

- 공간을 욕실, 침실, 주방, 놀이방, 현관, 안전 공간의 6개 방으로 다시 나눴습니다.
- 캐릭터가 걸을 수 있는 바닥 범위를 방마다 정했습니다.
- 거울, 세면대, 침대처럼 원래 방에 있는 물건은 움직이지 않게 했습니다.
- 행동으로 얻은 비누, 수건, 컵, 가방 같은 물건은 알맞은 방에만 나타나게 했습니다.
- 획득 물건은 아무 곳에나 놓지 않고 세면대 옆, 선반, 식탁 위처럼 정해진 자리에 붙도록 바꿨습니다.
- 캐릭터의 앞·뒤·왼쪽·오른쪽 모습과 행동 모습을 한 그림 모음으로 연결했습니다.

### 결과

- 현재 방과 맞지 않는 물건은 놓을 수 없게 됐습니다.
- 물건을 터치하면 캐릭터가 가까이 이동한 뒤 관련 행동을 하도록 연결했습니다.
- 아이별·공간별 배치 내용이 기기에 저장되도록 유지했습니다.
- 자동 검사에는 6개 방과 보상 연결을 확인하는 항목이 추가됐습니다.

- 모든 휴대폰 크기에서 캐릭터의 발과 그림자가 바닥에 자연스럽게 붙어 보이는지
- 6개 공간의 모든 물건을 터치했을 때 이동과 행동이 어색하지 않은지

## 2. Android 설치 파일과 QR 문제

### 문제

- 웹 미리보기에서 흰 화면만 보인 적이 있었습니다.
- APK는 Android 설치 파일이므로 Chrome이나 Windows에서 앱처럼 직접 실행할 수 없습니다.
- QR 주소를 만들 때 Windows가 Wi-Fi 주소 자동 조회를 허용하지 않은 적이 있습니다.
- QR 재생성 도구 중 하나는 사용자 폴더 접근 권한 오류가 났고, 다른 하나는 필요한 추가 기능이 설치되어 있지 않아 실패했습니다.

### 시도

- 웹 미리보기 대신 Android용 최종 설치 파일을 새로 만들었습니다.
- PC에서 설치 파일을 내려받게 하는 간단한 다운로드 서버를 실행했습니다.
- PC 안에서 다운로드 주소가 응답하는지 확인했습니다.
- 자동 조회가 실패한 Wi-Fi 주소는 `ipconfig` 결과에서 확인했습니다.

### 결과

- Android 최종 설치 파일 생성에 성공했습니다.
- 파일 위치: `build/app/outputs/flutter-apk/app-release.apk`
- 파일 크기: 약 217.3MB
- PC 내부 다운로드 응답은 정상 상태(HTTP 200)였습니다.
- 확인한 Wi-Fi 주소는 `192.168.45.14`였습니다.
- QR과 직접 주소를 사용자에게 전달했습니다.

### 중요: 아직 완료로 볼 수 없는 점

- 휴대폰에서 QR을 읽고 다운로드·설치·첫 실행까지 성공하는 전체 과정은 이 작업 기록 시점에 다시 확인하지 못했습니다.
- PC와 휴대폰이 같은 Wi-Fi에 있어야 하며, 다운로드하는 동안 PC의 서버가 켜져 있어야 합니다.
- Wi-Fi 주소가 바뀌면 기존 QR은 작동하지 않으므로 새 QR을 만들어야 합니다.

# 2026-08-14 — 아바타 공간 좌표·가구·걷기 자산 재점검

## 발견한 문제

- 배경은 세로형 원본인데 화면에서는 잘라 채우고, 가구는 전체 화면 비율로 놓아 두 좌표가 서로 어긋났다.
- 바닥 가구도 그림의 중심점을 위치로 사용해 욕조·세면대·선반·신발장이 공중에 떠 보였다.
- 침실 옷장이 창문을 가렸고 주방 싱크대와 식기장이 약 61% 겹쳤다.
- 공간 꾸미기 화면에는 기본 가구가 빠져 일반 아바타 화면과 다른 방처럼 보였다.
- 왼쪽 걷기 원본의 투명 영역 아래에 다음 행의 머리 조각이 섞여 있어 옆으로 걸을 때 발밑에 머리가 나타났다.
- 현관 실내에 신호등과 횡단보도를 기본 가구로 연결한 테마 불일치가 있었다.

## 적용한 수정

- 모든 배경·가구·획득 물건·캐릭터가 `941 x 1672` 비율의 같은 화면 영역과 0~100 좌표를 사용하게 했다.
- 바닥 아래쪽 가운데, 벽 중심, 표면 기준의 세 가지 물건 기준점을 만들었다.
- 가구의 보이는 범위, 누르는 범위, 부딪힘 영역, 캐릭터 접근점을 서로 분리했다.
- 침실·주방·생활 공간·현관 가구를 실제 바닥선과 빈 벽 기준으로 다시 배치했다.
- 공간 꾸미기 화면도 같은 기본 가구와 같은 좌표 변환을 사용하게 했다.
- 현관문은 방 구조 그림으로 명시하고, 실내와 맞지 않는 신호등·횡단보도 기본 가구는 제거했다. 안전 연습용 획득 물건은 유지했다.
- 걷기 정규화 도구가 다른 프레임에서 섞인 큰 조각을 제거하고, 검사 도구가 각 걷기 칸에 큰 그림 덩어리가 하나인지 확인하게 했다.
- 이동 시간을 6초에서 4초로 줄이고 걷기 반복을 1.2초에서 0.8초로 맞춰 바로 전 버전보다 정확히 1.5배 빠르게 했다.
