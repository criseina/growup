# GrowUp 개발 단계

마지막 갱신: 2026-08-13

## 완료한 큰 작업

- [x] 앱의 원칙과 아이·부모 화면 기준 정리
- [x] 61개 행동 카드와 행동 순서 연결
- [x] 모든 행동 카드의 그림 연결
- [x] 홈 → 행동 고르기 → 아이 선택 → 부모 확인 → 성장 기록 연결
- [x] 부모 메모와 아이별 기록 저장
- [x] 성장 기록 요약과 기간·상태 필터
- [x] 첫 성장 경험과 아바타·공간 아이템 연결
- [x] 6개 아바타 공간의 걷는 영역, 기본 물건, 아이템 배치 자리 구성
- [x] Android 설치 파일 만들기

## 현재 집중하는 단계

기능을 더 늘리기보다 실제 휴대폰에서 전체 흐름을 반복 점검하는 단계입니다.

- [ ] QR 다운로드부터 설치, 첫 실행까지 실제 휴대폰에서 다시 확인
- [ ] 작은 화면과 큰 화면에서 글자·그림이 잘리지 않는지 확인
- [ ] 61개 카드 각각의 선택·기록·보상이 올바른지 확인
- [ ] 아바타가 물건까지 자연스럽게 이동하고 동작하는지 공간별 확인
- [ ] 앱을 껐다 켜도 메모, 보상, 배치 위치가 남는지 확인

## 프로토타입 다음 단계

1. 발견된 오류를 고치고 실제 가족 시험을 진행합니다.
2. 기록 내보내기와 가져오기를 안정화합니다.
3. 필요한 경우에만 온라인 백업과 계정을 설계합니다.
4. 앱 아이콘, 설치 업데이트, 개인정보 안내를 정리합니다.
5. Play Store 출시 전용 검사를 진행합니다.

## 완료의 뜻

코드가 작성됐다는 이유만으로 완료라고 하지 않습니다. 화면에서 동작하고, 저장 후 다시 열어도 유지되며, 자동 검사와 실제 휴대폰 확인을 모두 통과해야 최종 완료입니다.
