# 성장 보상과 아바타 공간

GrowUp의 보상은 점수나 돈이 아닙니다. 아이가 새로운 행동을 경험한 순간을 아바타와 공간에 남겨 따뜻하게 기념하는 방식입니다.

## 기본 원칙

- 같은 아이가 같은 행동으로 받는 첫 성장 보상은 한 번만 만듭니다.
- 코인, 상점, 구매, 순위, 연속 출석, 실패 벌점은 넣지 않습니다.
- 보상은 아바타가 입는 물건 또는 공간에 놓는 물건입니다.
- 한 아이의 기록과 보상이 다른 아이에게 섞이지 않게 따로 저장합니다.
- 아이가 보상을 얻기 위해 실제 능력보다 높은 선택을 누르도록 유도하지 않아야 합니다. 축하는 결과의 등급보다 시도와 성장 경험에 초점을 둡니다.

## 화면 연결

- 아이 카드: 선택 결과를 화면에 남기고, 첫 성장 보상이 있으면 알립니다.
- 부모 화면: 행동 설명, 관찰 기준, 메모, 보상 내용을 확인합니다.
- 성장 기록: 선택과 메모를 날짜별로 확인합니다.
- 아바타: 얻은 옷과 소품을 적용합니다.
- 공간: 얻은 물건을 알맞은 방의 정해진 자리에 놓고 상호작용합니다.

## 여섯 공간

| 공간 | 원래 놓인 물건 예 | 행동으로 얻는 물건 예 |
|---|---|---|
| 욕실 | 거울, 세면대, 욕조, 변기 | 비누, 수건, 칫솔과 치약, 샴푸 |
| 침실 | 침대, 전신 거울, 옷장 | 옷걸이, 옷 바구니, 개어 놓은 옷, 모자 |
| 주방 | 식탁, 식기장, 싱크대 | 컵, 수저, 그릇, 닦는 천 |
| 놀이방 | 낮은 선반, 책장 | 장난감 상자, 작은 책장, 빨래 바구니, 휴지통 |
| 현관 | 신발장, 현관문, 벽걸이 | 가방, 물병, 손수건과 물티슈, 우산 |
| 안전 공간 | 신호등, 횡단보도 | 안전 원뿔, 멈춤 표지, 횡단보도 매트, 도움 카드 |

## 기기 안에 저장하는 내용

- 첫 성장 경험
- 얻은 물건
- 아바타가 현재 입고 있는 물건
- 아이별·공간별로 놓은 물건과 위치
