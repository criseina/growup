# 성장 보상 시스템 MVP

GrowUp의 보상은 행동을 반복시키기 위한 점수나 재화가 아니다. 아이가 한 행동을 처음으로 혼자 해냈을 때, 그 성장 경험을 아바타와 공간에 남기는 방식이다.

## 규칙

- `independent` 상태로 처음 바뀔 때만 성장 이벤트를 만든다.
- 같은 아이·같은 Action Card에는 성장 이벤트와 보상을 한 번만 만든다.
- 코인, 상점, 구매, 랭킹, 연속 출석, 실패 패널티는 제공하지 않는다.
- 보상은 `avatar_item` 또는 `space_item`이며, 모든 상태는 프로필별로 저장한다.

## 저장 키

- `growth_events_v1`: 첫 독립 성공 이벤트
- `unlocked_items_v1`: 잠금 해제 아이템
- `avatar_state_v1`: 슬롯별 장착 아이템
- `space_state_v1`: 공간별 배치 아이템

기존 `action_card_levels_v1_*`, `action_observations_v1`, 아이 프로필 데이터는 변경하지 않는다.

## UI 연결

- 아이 카드: 첫 독립 성공 직후 축하와 잠금 해제 아이템 표시
- 홈: 성장 꾸미기 메뉴에서 아바타와 공간으로 이동
- 부모 상세: 해당 카드의 성장 이벤트와 잠금 해제 상태 표시
- 성장 기록: 성장 이벤트를 관찰 기록과 함께 표시
