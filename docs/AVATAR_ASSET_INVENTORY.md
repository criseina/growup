# 아바타 자산 전체 점검표

점검일: 2026-08-14

## 점검 당시 결론

현재 아바타 공간은 위치·충돌·상호작용 기능은 분리되어 있지만, 기본 오브젝트 그림은 배경 이미지에 합쳐져 있다. 캐릭터 이동 그림은 방향별 한 장뿐이고, 상호작용 그림도 네 종류뿐이라 일부 물건과 행동이 시각적으로 일치하지 않는다. 획득 보상 알림은 이모지를 사용하고 공간 꾸미기는 그림 모음을 사용해 같은 물건이 다르게 보인다.

## 현재 자산

| 구분 | 현재 상태 | 판정 |
|---|---|---|
| 공간 배경 | 6개 공간 이미지가 있으나 기본 오브젝트 포함 | 분리 제작 필요 |
| 기본 오브젝트 | 코드의 위치·충돌·접근점만 있고 독립 그림 없음 | 신규 제작 필요 |
| 획득 오브젝트 | 2개 그림 모음에 24종 존재 | 재사용 가능 |
| 화장실 획득 오브젝트 | 기존 다른 물건 그림을 재사용 | 고유 그림 필요 |
| 기본 캐릭터 | 앞·뒤·왼쪽·오른쪽과 네 가지 행동 그림 | 디자인 기준으로 사용 |
| 걷기 | 방향마다 한 자세 | 추가 프레임 필요 |
| 상호작용 | 사용·닦기·정리·손 흔들기 | 행동별 그림 필요 |
| 보상 알림 | 이모지 | 획득 오브젝트 대표 그림으로 통합 필요 |
| 꾸미기 보관함 | 획득 오브젝트 그림 모음 | 대표 그림으로 통합 가능 |

## 새로 제작할 순수 배경

- 욕실: 벽, 바닥, 창문, 문, 장식만
- 침실·옷방: 벽, 바닥, 창문, 장식만
- 주방: 벽, 바닥, 창문, 장식만
- 생활 공간: 벽, 바닥, 창문, 장식만
- 현관: 벽, 바닥, 열린 문과 바깥 풍경만
- 화장실: 벽, 바닥, 문, 장식만

## 독립 그림이 필요한 기본 오브젝트

- 욕실: 거울, 세면대, 욕조, 샤워기
- 침실·옷방: 침대, 전신 거울, 옷장, 서랍장
- 주방: 식탁, 식기장, 싱크대, 냉장고
- 생활 공간: 낮은 선반, 큰 책장
- 현관: 신발장, 현관문 터치 표시, 벽걸이, 신호등, 횡단보도
- 화장실: 변기, 작은 세면대, 물 내림 손잡이, 휴지걸이

현관문처럼 배경에 남는 구조물도 터치·가림 표현이 필요한 부분은 별도 앞/뒤 그림을 둘 수 있다.

## 대표 그림 통합 규칙

각 획득 물건은 `itemId`, 이름, 공간, 대표 그림 위치, 상호작용 그림 이름, 배치 규칙을 한 곳에서 관리한다. 보상 알림, 보관함, 배치된 물건, 상호작용 대상은 모두 같은 대표 그림을 사용한다. 이모지는 글자만 필요한 보조 표시 외에는 대표 그림을 대신하지 않는다.

## 기존 자산 기준

- 공간 화풍: `bathroom-v2.png`, `bedroom-v2.png`, `kitchen-v2.png`, `entrance-v2.png`, `toilet.png`
- 캐릭터 디자인: `avatar_motion_atlas.png`
- 획득 물건 색감과 선: `room_items_a.png`, `room_items_b.png`

새 그림은 위 자산의 따뜻한 수채화 색감, 동일 캐릭터 얼굴과 비율, 부드러운 선, 밝은 조명을 유지한다.

## 남은 후속 자산

- 현재 동작에 필요한 자산은 빠짐없이 연결했다.
- 출시 전 고도화 항목: 상의 외의 하의·신발·모자·가방도 모든 걷기/상호작용 자세에 자연스럽게 합성되는 방향별 착장 그림 모음. 현재는 상의 전신 착장과 모자·가방 대표 그림 겹치기를 유지한다.

아바타가 입는 옷은 기존 착용 합성 방식을 유지한다. 공간 물건과 달리 옷은 전신 캐릭터 자세에 따라 별도 착용 그림이 필요하므로 이번 공간 레이어 자산과 분리해 관리한다.
