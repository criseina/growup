# GrowUp 공통 아바타 캐릭터 시스템

최종 갱신: 2026-08-14

## 한눈에 보는 원칙

- 캐릭터 위치는 그림 중앙이 아니라 **두 발이 닿는 바닥점**이다.
- 모든 캐릭터 칸은 `360 x 600` 픽셀이고 바닥점은 `(180, 580)`이다.
- 대기, 4방향 걷기, 상호작용, 옷 착용 상태 모두 앱 표시 배율 `1.0`을 쓴다.
- 한 번의 이동은 기존 1.2초에서 정확히 5배인 6초가 되었다. 따라서 속도는 기존의 `0.2`배다.
- 방이 바뀌어도 같은 이동·방향·프레임·충돌 시스템을 쓴다.

## 처리 흐름

1. 방 안 위치를 0~100 범위의 바닥 좌표로 저장한다.
2. 화면 크기에 맞춰 바닥 좌표를 화면 좌표로 바꾼다.
3. 캐릭터의 발바닥 중앙을 그 화면 좌표에 맞춘다.
4. 목적지까지 직선이 막히면 가구의 바깥 모서리를 경유하는 가장 짧은 길을 찾는다.
5. 이동 방향에 따라 앞·뒤·왼쪽·오른쪽 걷기 4프레임을 반복한다.
6. 물건을 누르면 물건의 도착점까지 이동하고, 지정 방향을 본 다음 전용 동작을 실행한다.

## 공통 코드

- `AvatarCharacterMetrics`: 캔버스, 발바닥 기준점, 앱 표시 배율
- `AvatarMovementSystem`: 속도, 이동 시간 배분, 방향 판단, 장애물 우회
- `AvatarAnimationRegistry`: 대기·걷기·상호작용 이미지 경로와 방향 행
- `RoomObject`: 물건 위치, 충돌 영역, 도착점, 상호작용 방향과 시간
- `tool/normalize_avatar_atlases.py`: 원본 이미지를 공통 칸에 맞추는 도구
- `tool/verify_avatar_atlases.py`: 칸 크기와 발바닥 위치를 검사하는 도구

## 현재 걷기 이미지

- 앞, 뒤, 왼쪽, 오른쪽 각 4프레임
- 오른쪽 프레임은 같은 왼쪽 프레임을 좌우 반전해 체형·크기·발 위치를 정확히 맞춘다.
- 새 프레임을 추가할 때도 원본을 앱에서 임의 확대·축소하지 않고 먼저 정규화 도구를 거친다.

## 자동 검사

- 모든 정규화 이미지의 칸 크기: `360 x 600`
- 모든 칸의 보이는 그림 최하단: `y = 580`
- 앱 표시 배율: `1.0`
- 걷기 방향: 4방향
- 방향별 걷기 프레임: 4장
- 이동 시간: 총 6초, 경유 구간 거리 비율대로 나눔
- 이동 선분: 이동 가능 바닥 안이며 장애물을 통과하지 않음
- 물건 도착점: 바닥 안이고 충돌 영역 밖임

## 아직 필요한 전용 상호작용 그림

현재 여러 행동이 같은 계열 동작을 함께 사용한다. 기능은 동작하지만 아래 항목은 물건과 캐릭터가 합쳐진 오래된 그림을 쓰거나, 세부 행동별 전용 프레임이 부족하다. 억지로 다른 그림을 연결하지 않고 다음 제작 대상으로 관리한다.

| 우선 | 공간 | 물건/행동 | 필요한 그림 |
|---|---|---|---|
| 높음 | 화장실 | 변기에 앉기 | 변기 없이 캐릭터만 앉는 옆모습 프레임 |
| 높음 | 욕실 | 세면대 손·얼굴·발 씻기 | 세면대 없이 각 행동을 하는 캐릭터 프레임 |
| 높음 | 욕실 | 칫솔·치약 | 칫솔질, 치약 묻히기 전용 프레임 |
| 높음 | 욕실 | 수건 | 닦기, 걸기 전용 프레임 |
| 보통 | 침실 | 옷장·옷 | 입기, 벗기, 단추·지퍼, 정리하기 세부 프레임 |
| 보통 | 주방 | 컵·수저·그릇 | 마시기, 먹기, 그릇 정리 전용 프레임 |
| 보통 | 놀이방 | 책·장난감·바구니 | 각 물건 꺼내기와 정리하기 프레임 |
| 보통 | 현관 | 가방·우산·모자 | 각 물건 챙기기와 착용 프레임 |

이 그림을 만들 때도 같은 아이, 같은 옷, 투명 배경, `360 x 600`, 발바닥 `(180, 580)` 규칙을 적용한다.
