# 아바타 공간 기준

마지막 갱신: 2026-08-14

이 문서는 GrowUp 아바타 공간의 기준입니다. 아이에게는 기술 구조를 보여 주지 않고, `누르기 → 걸어가기 → 도착하기 → 행동하기 → 반응 보기`의 단순한 경험만 제공합니다.

## 핵심 흐름

행동을 경험함 → 성장 물건을 얻음 → 해당 공간의 보관함에서 찾음 → 정해진 자리에 놓음 → 캐릭터와 상호작용함

## 여섯 공간

| 공간 | 연결 행동 |
|---|---|
| 욕실 | 위생 |
| 침실·옷방 | 옷 입기 |
| 주방·식사 공간 | 식사 |
| 생활 공간 | 물건과 집안일 |
| 현관·바깥 준비 | 외출 준비, 안전과 도움 요청 |
| 화장실 | 화장실 사용 |

별도였던 안전 공간은 현관과 합쳤습니다. 기존에 안전 공간에서 얻거나 놓은 물건은 삭제하지 않고 현관으로 옮깁니다.

## 공간을 이루는 세 부분

1. 배경: 벽, 바닥, 문, 창문, 선반처럼 직접 누르지 않는 환경입니다.
2. 원래 있는 물건: 세면대, 침대, 식탁, 변기처럼 처음부터 있고 움직이거나 삭제할 수 없는 물건입니다. 짧게 누르면 캐릭터가 다가가 행동합니다.
3. 행동으로 얻는 물건: 비누, 컵, 가방, 화장지처럼 성장 경험으로 얻습니다. 알맞은 공간에만 나타나고 정해진 자리에 놓을 수 있습니다.

### 실제 화면에 쌓는 순서

1. 순수 배경
2. 벽에 붙은 뒤쪽 기본 물건
3. 발 위치보다 뒤에 있는 기본·획득 물건
4. 캐릭터 그림자
5. 캐릭터
6. 발 위치보다 앞에 있는 기본·획득 물건
7. 터치 영역과 안내 버튼

따라서 가구는 배경에 그려 넣지 않습니다. 물건마다 그림, 화면 위치, 크기, 부딪힘 범위, 누르는 범위, 캐릭터가 설 자리, 화면 앞뒤 기준을 따로 가집니다.

## 이동 기준

- 모든 공간은 가로와 세로를 각각 0부터 100까지 쓰는 같은 위치 기준을 사용합니다.
- 캐릭터 위치는 머리나 몸의 가운데가 아니라 발이 닿는 지점입니다.
- 방마다 걸을 수 있는 바닥 범위와 지나갈 수 없는 가구 범위를 정합니다.
- 캐릭터는 바닥 밖으로 나가거나 가구를 통과하지 않습니다.
- 위로 가면 뒷모습, 아래로 오면 앞모습, 좌우로 가면 해당 방향 모습을 보여 줍니다.
- 각 방향은 발과 팔이 번갈아 보이는 3장의 걷기 그림을 반복합니다.
- 이전보다 약 30% 느린 1.2초 이동 전환을 사용합니다.
- 캐릭터 그림 아래의 투명 여백을 보정해 보이는 발과 그림자가 맞닿게 합니다.

## 물건 사용 방법

- 원래 있는 물건을 짧게 누름: 다가가서 상호작용
- 원래 있는 물건을 길게 누름: 아무 변화 없음
- 획득 물건을 짧게 누름: 다가가서 상호작용
- 획득 물건을 길게 누름: 현재 공간 꾸미기 열기
- 꾸미기에서 획득 물건을 길게 눌러 끌기: 허용된 가까운 자리에만 배치
- 잘못된 공간이나 자리: 배치를 거부하고 쉬운 안내 표시

## 공간별 예

- 욕실: 세면대·욕조·샤워기 / 비누·수건·칫솔과 치약·샴푸
- 침실·옷방: 옷장·거울·서랍·침대 / 옷걸이·옷 바구니·개어 놓은 옷·모자
- 주방: 싱크대·냉장고·식탁·식기장 / 컵·수저·그릇·닦는 천
- 생활 공간: 선반·책장·수납 공간 / 장난감 상자·작은 책장·빨래 바구니·휴지통
- 현관: 신발장·문·벽걸이·신호등·횡단보도 / 가방·물병·물티슈·우산·안전 물건
- 화장실: 변기·물 내림 손잡이·작은 세면대·휴지걸이 / 화장지·물티슈·비누·수건

## 옷 꾸미기

머리, 모자, 상의, 하의, 신발, 가방·액세서리를 서로 다른 항목으로 저장합니다. 얻지 않은 물건은 선택할 수 없습니다. 공간에 놓는 물건과 아바타가 입는 물건은 별도로 관리합니다.

## 기존 기록 보호

- 안전 공간 배치 기록은 현관 배치 기록으로 옮깁니다.
- 보상 연결이 바뀌어도 이미 완료한 행동을 읽어 현재 보상을 함께 열어 줍니다.
- 예전 자유 위치에 있던 물건은 새 배경의 가장 가까운 허용 자리로 옮깁니다.

## 확인된 데이터 문제

첨부 명세에는 `물건과 집안일`을 10개라고 적으면서 11개 행동을 나열했습니다. 현재 실제 앱 데이터에는 10개가 있습니다. 이번 작업에서는 행동을 몰래 삭제하거나 추가하지 않았습니다. 어떤 행동을 최종 목록에 둘지는 별도 콘텐츠 검토에서 결정합니다.
