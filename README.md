# GrowUp

아이의 일상 행동을 평가하지 않고 관찰하고 기록하는 Flutter 앱입니다.

## 지금 구현된 범위

- 61개 행동 카드와 카테고리별 행동 순서
- 아이 모드, 부모 확인, 부모 메모, 성장 기록
- 아이별 프로필과 기기 안 저장
- 첫 성장 경험에 연결되는 아바타·공간 아이템
- 욕실, 침실, 주방, 놀이방, 현관, 안전 공간의 6개 아바타 공간
- 공간 안 걷기, 기본 물건 터치, 획득 물건 배치와 상호작용
- Android 설치 파일(APK) 만들기

## 현재 상태

앱의 주요 기능을 연결한 프로토타입 단계입니다. 실제 가족이 반복해서 사용해 보며 화면 크기, 기록 편의성, 아바타 동작을 다듬어야 합니다. 앱 마켓 출시용 완성판은 아닙니다.

최근 작업에서 무엇이 문제였고 어떻게 바뀌었는지는 [최근 작업 기록](docs/RECENT_WORK_LOG.md)을 확인하세요.
